# ARTEMIS Control Plane Minimal Simple View - Handoff

The Control Plane simple mode was reduced after the compact operations cut
still showed too much information.

## What Changed

- Header height reduced.
- Principle cards and explanatory subtitle hidden from the first read.
- Auxiliary state/human/how-to panels hidden from simple mode.
- Source lines and provider/operator chips hidden from simple mode.
- Status and operation are now short, low-height rows.

## Remaining Boundaries

- Technical detail remains available through `Mostrar visao tecnica completa`.
- This does not start agents or connect provider auth.
- This does not mutate remote state or spend tokens.
